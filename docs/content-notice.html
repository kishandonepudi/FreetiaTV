Content notice

Freetia TV is a player

Freetia TV plays M3U/M3U8 playlists that you add. It does not host, sell, recommend or provide any channels or streams. The store builds ship with no playlist at all.

Starter playlist in the GitHub build

For convenience, the GitHub (foss) build adds one playlist on first run: the community-maintained public list of Indian channels from the iptv-org/iptv project. That list only links to streams that their owners make publicly available. Freetia TV does not control or check those streams. You can delete the playlist in Settings → Playlists.

Your responsibility

You are responsible for making sure you have the right to watch the content in any playlist you add.

Takedown requests

Freetia TV stores no streams, so it cannot remove them. Send requests about a stream to its owner, or, for the starter list, to the iptv-org/iptv project.
