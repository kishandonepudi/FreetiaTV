Freetia TV

A free, ad-free TV player for Android phones, tablets, Android TV and Fire TV. Paste your M3U playlist link and watch with your remote.

Download the latest release

Freetia TV is a player only. It does not sell, host or provide channels. You add playlists you have the right to use. See the content notice.

Features

  • Works fully with a TV remote: Up/Down changes channel, OK opens the list, number keys jump to a channel.
  • Save any number of playlists, ordered by priority.
  • Favourites, regions, audio languages, captions and quality control.
  • Child Safe Mode and channel locks with a PIN.
  • Sleep timer, large text and a high-contrast mode.

Which file do I download?

  • FreetiaTV-…-foss.apk: for installing yourself on phones, Android TV and Fire TV. It adds one removable starter playlist on first run.
  • FreetiaTV-…-store.apk: the same app with no playlist added.

Install on Fire TV

  1. On the Fire TV home screen, search for and install the Downloader app.
  2. Go to Settings → My Fire TV → Developer options and allow Install unknown apps for Downloader. If Developer options is hidden, open Settings → My Fire TV → About and press OK on the device name 7 times.
  3. Open Downloader and enter the release page address: https://github.com/freetia-tv/freetia-tv/releases/latest
  4. Select the foss.apk file, then choose Install.
  5. Open Freetia TV from Your Apps & Channels.

Install on Android TV

  1. Install a file manager or the Downloader app from Google Play on the TV.
  2. Allow it to install unknown apps: Settings → Apps → Security & restrictions → Unknown sources (wording varies by TV).
  3. Download the foss.apk from the release page and open it to install.

Install on a phone or tablet

  1. Open the release page in your phone’s browser and tap the foss.apk file.
  2. When asked, allow your browser to install apps, then tap Install.

Verify your download

Each release includes SHA256SUMS.txt. Compare it with the checksum of the file you downloaded.
